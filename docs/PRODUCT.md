# ChatPye Workspace — Product Definition

**Legal entity:** Pye Interactive Limited  
**Brand:** ChatPye · **Product:** ChatPye Workspace · **AI tutor:** Pye · **Evidence:** SkillProof (integrated)

## Value proposition

> ChatPye turns learning plans, tutorials and real work into evidence employees can use in performance reviews — and managers can trust.

## User segments

| Segment | Job to be done |
|---------|----------------|
| Employee | Learn, apply, prove competence, control visibility |
| Manager | Assign growth plans, review evidence, run reviews |
| Org admin | Members, billing, frameworks, audit |
| Personal learner | YouTube/PDF learning without an organisation |

## Core journeys

See `docs/USER_JOURNEYS.md`.

## Release scope

In scope for web launch: marketing, personal workspace, org workspace, Growth Plans, SkillProof review, billing, audit.  
Out of scope: desktop control, surveillance, ChatPye Kids, autonomous hiring.

## Brand rules

- Present SkillProof as a capability inside ChatPye, not a separate company.
- Pye is the tutor; ChatPye is the product brand.
