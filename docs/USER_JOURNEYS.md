# User Journeys — ChatPye Workspace

## Journey A — Employee starts private learning

1. Sign up → select “I’m here to grow my skills”
2. Paste YouTube URL on `/app/import`
3. Resource persisted; async processing
4. Enter workspace; chapters/objectives appear progressively
5. Learn with Pye; save notes/bookmarks
6. Complete quiz or task → submit evidence
7. Draft competency assertion → choose private or shared

**Baseline gap:** Steps 3–7 partially exist on `/workspace`; need resource jobs + Growth Record.

## Journey B — Manager creates a Growth Plan

1. Create organisation → invite employee
2. Create 30/60/90-day plan with SMART objectives
3. Add resources; Pye drafts tasks/quizzes
4. Manager edits and publishes
5. Employee sees visibility notice → accept/decline
6. Manager sees agreed progress and evidence only

**Baseline gap:** Courses/HR exist; Growth Plan entity missing.

## Journey C — Evidence and competency review

Evidence states: Draft → Submitted → Analysing → Ready for review → Accepted / Revision requested / Declined

**Baseline gap:** SkillProof API stubs exist; full lifecycle + audit missing.

## Journey D — Performance review

Scheduled review with objectives, evidence, reflections, manager feedback, next actions.

**Baseline gap:** Not implemented.
