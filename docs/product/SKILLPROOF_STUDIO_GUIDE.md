# SkillProof Studio Guide

## For managers and trainers

1. Create a course from **Dashboard → Courses**.
2. Assign it to learners by email. They receive it in **Workspace → Courses**.
3. Import or paste a public YouTube tutorial. The workspace keeps the video when the user signs in, then prepares transcript, chapters and chat context.
4. Use the video workspace to validate the learning experience. Select **Create SkillProof Challenge from this video** when the challenge builder is enabled.
5. Define the project outcome, rubric, required evidence and review criteria. For the MVP, use a GitHub, OneDrive, Google Drive or demo link as evidence.
6. Review submitted evidence alongside task completion, learner reflections and competency assertions. Treat system signals as decision support; a manager makes the final verification decision.

## For learners and employees

1. Open an assigned course or paste a tutorial URL on the homepage.
2. Use the **Learning map** to jump to the part of the tutorial needed for your next task.
3. Ask the AI tutor about the content, then use **SkillProof task** to select VS Code or Excel, complete the steps and request a graduated hint.
4. Add a GitHub repository, workbook, demo or document link and explain what you built and why.
5. Use **Snip** on an uploaded video to extract visible code or text. Public YouTube frame capture is blocked by browser security; ask the tutor about the current timestamp instead.
6. Use **Save clip** to save a timestamp range as learning evidence. It is a bookmarkable time range, not an exported video file.

## Competency terms

- **Competency:** a skill the organisation wants to assess, such as modelling a balance sheet or debugging an API.
- **Evidence:** a link, reflection, submission, quiz or observed task signal that supports the competency.
- **Assertion:** the platform's structured claim that a learner demonstrated the competency at a stated level.
- **Reviewer status:** whether the claim is system-generated, manager-reviewed or verified.

## Responsible use

SkillProof Studio is designed to support learning, not covertly monitor people. Any future desktop companion action—such as reading an active workbook or proposing a change—must be opted into, visible in the interface and recorded as part of the learner's evidence trail.
